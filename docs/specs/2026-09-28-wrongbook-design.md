# 错题本功能完整设计方案

- 日期：2026-09-28
- 状态：已确认（待进入实施计划）
- 范围：对现有错题本（`src/lib/wrongbook.ts` + `WrongbookScreen` + `ReviewScreen`）的重构与扩展

## 1. 背景与目标

现有错题本已经具备「采集 → 复习 → 清空」的最小闭环：练习时填错的单词自动入本（按「句子文本 + 词位置」去重），按艾宾浩斯固定阶梯排期，到期后按「整句重填」复习，localStorage 持久化。

本次重构目标：把错题本从「电子笔记本」升级为「会算账、会督促、会上瘾的学习管家」。核心一句话：**让学习者每天愿意打开、愿意把当天复习做完、坚持住，错词自然就记住了。**

## 2. 已确认的关键决策

通过方向对齐，以下决策已由用户确认：

| 维度 | 决定 |
|------|------|
| 核心定位 | **激励坚持优先**（游戏化、连胜、正反馈是重心） |
| 复习形式 | 保留「整句重填」，新增「看词选义（四选一）」「听音默写」「翻卡回忆」 |
| 记忆算法 | **SM-2 自适应**（每次自评动态调间隔），取代固定阶梯 |
| 游戏化 | **完整游戏化**（经验值、等级、连胜、成就徽章） |

以下三点由我默认、需用户后续确认（见 §14）：

1. 掌握标准 = 连续答对 ≥4 次 且 间隔 ≥21 天
2. 今日复习默认**混合出题**（非固定单一题型）
3. 答错**不惩罚连胜**，只降排期

## 3. 设计原则

1. **以「今日任务」为轴心** —— 打开第一眼看到「今天要复习几个」，一键开始，零启动成本。
2. **即时正反馈，不惩罚** —— 每做一题立刻给 XP / 连击 / 进度；答错只影响下次排期，不扣分、不清连胜。
3. **成长看得见** —— 连胜、等级、徽章、统计图，让「坚持」本身有回报。
4. **YAGNI** —— 后置项明确列出，不在一期实现。

## 4. 信息架构

错题本从「一屏列表」升级为**三标签页**：

### Tab ① 今日复习（首页）

- 顶部：问候 + 🔥 连胜 N 天 + 今日进度环（已复习 / 待复习）
- 醒目的「开始今日复习」大按钮（显示到期数量）
- 逐题复习会话：四种题型混合 + 四档自评 + XP/连击反馈

### Tab ② 我的错词（词库）

- 全部错词列表，带状态徽章（新学 / 学习中 / 已掌握）
- 搜索、按状态 / 来源模板筛选、排序
- 点词条 → 单题练习（可选任一种题型）
- 批量操作：移入已掌握 / 删除 / 清空

### Tab ③ 统计（成长）

- 等级 + XP 进度 + 连胜 + 累计复习数
- 打卡热力图、正确率趋势、薄弱词 TOP、成就徽章墙

## 5. 数据模型（v2）

### 5.1 词条 `WrongEntry`

```ts
interface WrongEntry {
  key: string            // `${normalize(en)}|${wordIndex}`（不变）
  en: string
  zh: string
  word: string
  wordIndex: number
  addedAt: number        // 首次入本时间戳

  // ── SM-2 字段 ──
  repetition: number     // 连续答对次数
  intervalDays: number   // 当前间隔（天）
  easeFactor: number     // 难度系数，默认 2.5，下限 1.3
  dueAt: number          // 下次到期时间戳

  // ── 统计字段 ──
  reviews: number        // 累计复习次数
  lapses: number         // 遗忘 / 答错次数
  lastReviewAt: number

  status: 'new' | 'learning' | 'mastered'
}
```

> `status` 为派生字段，不单独落库也可：`new` = 从未复习（`reviews === 0`）；`learning` = 复习过但未达掌握标准；`mastered` = 满足 §6.2 掌握标准。

### 5.2 全局统计 `Stats`（独立 key `stats:v1`）

```ts
interface Stats {
  xp: number
  streakDays: number
  lastStudyDate: string            // YYYY-MM-DD，用于判连胜
  reviewCount: number              // 累计复习次数
  dailyHistory: Record<string, number> // 日期 → 当日复习数（热力图）
}
```

## 6. SM-2 记忆算法

每次复习完按「质量 q」更新词条。

### 6.1 四档自评 → q 映射

| 自评 | q |
|------|---|
| 忘记 | 2 |
| 模糊 | 3 |
| 记得 | 4 |
| 轻松 | 5 |

### 6.2 SM-2 规则

- **q < 3（忘记）**：`repetition = 0`，`intervalDays = 1`
- **q ≥ 3**：
  - `repetition === 0` → `intervalDays = 1`
  - `repetition === 1` → `intervalDays = 6`
  - 否则 → `intervalDays = round(intervalDays × easeFactor)`
  - `repetition += 1`
- **easeFactor 更新**：`EF' = EF + (0.1 − (5 − q) × (0.08 + (5 − q) × 0.02))`，下限 1.3
- **到期**：`dueAt = now + intervalDays`（天 → 毫秒）
- **掌握**：`repetition ≥ 4 且 intervalDays ≥ 21` → `status = 'mastered'`

### 6.3 客观题型的 q 自动映射

| 题型 | 对 q4 | 中间 | 错 q≤2 |
|------|-------|------|--------|
| 整句重填 | 一次提交全对 | 提交 2 次 → q2 | 提交 ≥3 次 → q1 |
| 看词选义 | 一次选对 | — | 选错 → q1 |
| 听音默写 | 一次拼对 | 错后再对 → q2 | — |
| 翻卡回忆 | 主观四档，直接取 q | | |

> 注：客观题以「提交/尝试次数」近似记忆质量；翻卡为主观自评。具体阈值可在实现期微调。

## 7. 四种复习形式

| 形式 | 玩法 | 评分 | 定位 |
|------|------|------|------|
| 整句重填（现有） | 看中文，填出整句每个词 | 客观 | 最严格、综合 |
| 看词选义 | 给中文/英文，四选一选对应项 | 客观 | 碎片快速刷 |
| 听音默写 | 播放发音，凭听拼写单词 | 客观 | 练听力拼写 |
| 翻卡回忆 | 看英文想中文（可反向），点翻面 | 主观四档 | Anki 式、最轻 |

- **今日复习**默认混合出题：按到期词随机，题型加权（翻卡/四选一常见，听写/整句偶尔）。
- **我的错词**页可单练任一种题型。

## 8. 游戏化体系

- **经验值 XP**：每完成一次复习 +10~20，按题型难度加权（翻卡 < 四选一 < 听写 < 整句重填）；答错给保底 5 XP。
- **等级**：`level = floor(sqrt(xp / 100)) + 1`（越升越慢）+ 升级动画。
- **连胜 Streak**：自然日内完成 ≥1 次复习续一天，中断归零，首页 🔥 醒目。
- **成就徽章**（达成弹 toast + 徽章墙亮起）：
  - 首次复习 / 复习 10·50·100·500 次
  - 连胜 3·7·30 天
  - 掌握 10·50·100 词
  - 单日复习 20·50 次
- **反馈动效**：答对绿勾 + 连击计数；每 10 连击额外加分；答错温和提示不惩罚。

## 9. 统计看板

等级 + XP 进度条 + 连胜 + 累计复习数 / 打卡热力图（GitHub 式）/ 掌握率 / 正确率趋势（7·30 天折线）/ 薄弱词 TOP 10（`lapses` 最多）。
